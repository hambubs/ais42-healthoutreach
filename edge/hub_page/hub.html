📡 MMU Hub — Sync Offline Alerts

Transfer emergency SOS alerts from the offline ESP32 gateway to the command console

1 Copy from the tablet

On the tablet (while connected to MMU-GATEWAY Wi-Fi), open 192.168.4.1/hub, tap Pull alerts, then tap Copy JSON.

2 Paste below and sync

Switch the tablet to your internet Wi-Fi, then paste the copied data here:

💡 What happens when you click Sync?
The alerts are sent to the command console and appear instantly in the live SOS feed on the map. Each alert shows the emergency type, priority, and the AI's recommended dispatch mode (ambulance, UAV, helicopter, etc.).
Full offline demo flow:
1. Phone in airplane mode → joins MMU-GATEWAY Wi-Fi → captive portal → tap SOS
2. Tablet on MMU-GATEWAY → 192.168.4.1/hub → Pull → Copy
3. Tablet switches to internet Wi-Fi → open this page → Paste → Sync
4. Alert appears live on the command console 🎉
