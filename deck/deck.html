Our Solution: One System, Three Layers

  • Spatial AI — DBSCAN settlement clustering + greedy MCLP places Mobile Medical Units for maximum area coverage
  • Offline Edge — ESP32 captive-portal SOS gateway: zero installs, AES-128 encrypted, works with no cellular
  • Multi-Modal Dispatch — ambulance · MMU van · 2W rider · UAV handoff · mobile outpost
  • Built on the provided datasets, enriched with acknowledged open data (HDX · DHS · WorldPop)

How It Fits Together

  • Data spine — provided 12,000-village dataset + 30,273-facility government directory
  • Optimizer — Need Score → underserved detection → DBSCAN → greedy MCLP → dual coverage metrics
  • Flask API + SQLite — 22 endpoints: optimize · SOS · sync · dispatch · supply-route · intel · DHS · HeiGIT
  • Ops Console (Leaflet) — live SOS feed, dispatch cards, UAV flight lines, live KPIs
  • Impact Dashboard (Streamlit) — before/after, WorldPop BLR pilot, live DHS API
  • Edge — ESP32 "MMU-GATEWAY" + any phone browser → hub tablet → sync when back online

The AI Core

Maximum area coverage, not minimum travel — eliminating medical dead zones

  • Need Score = 0.4·population + 0.3·risk + 0.3·inaccessibility
  • Underserved detection: Underserved_Area flag OR travel > 30 min
  • DBSCAN clusters underserved villages into settlement pockets
  • Greedy MCLP: maximize need-weighted population under scheduled care
  • Dual metrics: strict 30-min emergency + scheduled MMU circuit care (NHM model)
  • Circuits capped at ~400 villages per unit — block-scale, matching NHM practice

Impact — Before / After

13.82%  →  22.84%

  • 3 MMUs → 22.84% scheduled care = 14.75 million people newly served
  • 5 MMUs → 28.58%  ·  8 MMUs → 36.68%
  • 30-min emergency: 13.82% → 15.09% — the gap is bridged by dispatch modes
  • Zipline benchmarks: −61% blood delivery time (Rwanda) · −60% vaccine stock-outs (Ghana)

Zero-Connectivity SOS

The village has no cell coverage. The phone is in airplane mode.

  • Phone joins "MMU-GATEWAY" Wi-Fi → captive portal auto-opens — zero installs
  • One tap: Trauma / Maternal / Medicine
  • AES-128-CBC encrypted at rest (mbedTLS, random IV) → queue in flash
  • Hub tablet pulls the queue → carries it to coverage → syncs → alert appears LIVE on the console
  • Fallback: mobile /sos page + console demo triggers — the story never breaks
